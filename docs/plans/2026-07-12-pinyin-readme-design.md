# pinyin 中文 README 设计

## 目标

将仓库从内部 PoC 说明转为面向中文输入法社区的产品 README。项目正式名称统一展示为 `pinyin`，只提供中文版。README 需要让首次访问者快速理解前缀模式、判断是否适合自己的使用习惯，并优先通过 GitHub Releases 的 macOS 便携包开始使用。

## 叙事结构

采用产品优先结构。标题后直接用一句定位和一个完整输入示例说明：用户保持 macOS 英文输入源，通过默认前缀 `''` 临时进入拼音输入，再用同一字符串退出。随后解释它与 Shift、中英文输入源切换及自动切换工具的差异。

主体依次覆盖适用人群、功能特性、下载安装、首次输入、常用按键、配置、工作原理、限制、源码构建、贡献、项目缘起与致谢。个人经历保留在靠后的“为什么做 pinyin”中，作为产品动机而非整篇文档的叙事主线。

备选方案包括故事优先和技术优先。故事优先更适合后续社区宣传文章；技术优先更适合架构文档。两者都不如产品优先结构适合作为仓库首页。

## 事实边界

- 当前仅支持 macOS，并依赖辅助功能与输入监控权限。
- 便携包在目标 Mac 上不要求 Homebrew，核心输入转换由本地 `librime` 完成。
- README 不把项目描述为 macOS 输入源；它是全局键盘监听与文本回写程序。
- 默认前缀和后缀均为 `''`，候选键、翻页键、英文提交键以仓库配置为准。
- GitHub Releases 作为普通用户入口，源码构建和诊断命令放在开发者章节。
- 不声称存在仓库当前尚未提供的 GUI、后台服务、自动更新、代码签名公证或跨平台支持。
- 仓库尚无许可证文件，因此 README 不虚构许可证声明。

## 验证

对照 `rime-poc.toml`、CLI 帮助、运行与打包脚本检查所有默认值和命令。检查 README 中不再残留 PoC 定位或英文主体内容，并确认最后一节明确感谢 espanso 与 Rime。
